# assets/

Material de referência do cliente (logomarcas, gravações de aula fictícias). Leia o `README.md` desta
pasta antes de adicionar algo.

- **Nunca** versione dado pessoal real de aluno, responsável ou professor (LGPD, menores de idade).
- As gravações `.ogg`/`.mp4` são fictícias, servem à suíte `ia-real` e **ficam fora do Git** (`.gitignore`);
  o `compose.test.yaml` as monta somente leitura.
- Não use estes arquivos como código nem como fonte de verdade de regra de negócio.
